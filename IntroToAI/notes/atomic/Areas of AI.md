**Мини-словарь:**
- Natural Language Processing (NLP) — язык: понимать и порождать текст/речь.
- Knowledge Representation — как хранить то, что система «знает», чтобы этим пользоваться.
- Automated Reasoning — вывод следствий из представленных знаний.
- Machine Learning — улучшать поведение по данным / опыту, а не только руками прописать правила.
- Computer Vision — извлекать смысл из изображений/видео.
- Robotics — действовать в физическом мире: датчики + актуаторы.

Milestone: [[IAI Lection 1 - введение]]

### Концепт

Russell & Norvig (учебник курса; на слайдах Russel) дают **шесть major areas of concern** — это карта *чем занят ИИ на практике*, не замена [[Four AI definitions]]. Определения отвечают «что считать интеллектом»; области — «какие куски мира надо уметь».

Полный [[Turing Test]] тянет сразу несколько областей: NLP (говорить), KR + reasoning (знать и отвечать по делу), ML (учиться), vision и robotics (Full Test).

На следующем слайде «AI Onwards» к классике добавлены [[Computational creativity]] и biomimicry ([[Bioinspired AI]]) — это не седьмая и восьмая строки того же списка из шести, а «дальше».

### Под капотом

Шесть областей со слайда, по одной фразе «зачем»:

| Область | Без неё ломается |
|---|---|
| NLP | нет человеческого языка как канала |
| Knowledge Representation | некуда положить факты/правила |
| Automated Reasoning | знания лежат мёртвым грузом, нет вывода |
| Machine Learning | каждое умение надо вручную зашить |
| Computer Vision | нет входа с камеры / картинки |
| Robotics | нет тела в физическом мире |

Не сваливать шесть имён в один устный ответ без ролей: экзаменатор ждёт, что область — про **задачу**, не синоним «нейросеть».
