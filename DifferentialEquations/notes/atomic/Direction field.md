**Мини-словарь:**
- direction field (slope field) — набор коротких отрезков (стрелок) в точках сетки $(t_i,x_j)$, у каждого склон равен $f(t_i,x_j)$.
- integral curve — график решения; при условиях существования и единственности через каждую точку области проходит ровно одна.
- grid spacing $\Delta t,\Delta x$ — шаг сетки; длина отрезка $L$ должна быть меньше шага, иначе отрезки налезают друг на друга.

Milestone: [[DIFF Lection 1 - введение]]
Problem: [[DIFF Example 4]]; [[DIFF Example 5]]

### Концепт

Для $x'=f(t,x)$ производная в точке — это **наклон касательной** к графику решения. Значит, ещё не решив уравнение, в каждой точке плоскости можно сказать: «кривая, если пройдёт здесь, пойдёт под таким углом».

Поле направлений — ковёр таких коротких чёрточек. Решение — гладкая кривая, которая всюду гладит поле по шерсти. Начальное условие выбирает **одну** кривую из семейства.

Это геометрия, не таблица чисел: качественная картина, не значение в точке $t=3.7$.

### Под капотом

Явная форма 1-го порядка ([[Order of a differential equation]]):

$$
\frac{dx}{dt}=f(t,x)
$$

$\frac{dx}{dt}$ — склон касательной к $x(t)$. В любой $(t^*,x^*)$ из области значение $f(t^*,x^*)$ есть склон интегральной кривой **без** явной формулы решения.

**Определение.** Direction field (slope field) — короткие отрезки (стрелки) в узлах сетки $(t_i,x_j)$ на плоскости $(t,x)$, склон отрезка $=f(t_i,x_j)$.

Свойства из лекции:

- длина всех отрезков **одна и та же**; меняется только угол;
- поле показывает **локальное** поведение, это ещё не одна траектория;
- при стандартных условиях существования и единственности через каждую точку проходит ровно одна интегральная кривая.

Алгоритм построения:

1. выбрать область на плоскости $(t,x)$;
2. выбрать сетку точек;
3. выбрать фиксированную длину $L$;
4. в каждом узле $(t_i,x_j)$ посчитать $k_{ij}=f(t_i,x_j)$;
5. провести прямую $x-x_j=k_{ij}(t-t_i)$;
6. на ней взять отрезок длины $L$ с центром в $(t_i,x_j)$;
7. повторить по всем узлам.

Важно: $L$ меньше $\Delta t$ и $\Delta x$, чтобы отрезки не пересекались и не накладывались.

На практике поля рисуют MATLAB / Python / Maple; алгоритм нужен, чтобы читать картинку.

Плюсы: не нужна аналитическая формула; видно поведение; ловятся [[Equilibrium solution]]; работает и для нелинейных; легко интерпретировать.

Минусы: только качественно; точность от густоты сетки; вручную долго; нет численного значения в конкретной точке; грубая сетка может обмануть.

Связь с [[Isocline]]: изоклины — экономный способ не считать $f$ в каждом узле. Примеры: [[DIFF Example 4]], [[DIFF Example 5]], падение в [[Equilibrium solution]].
