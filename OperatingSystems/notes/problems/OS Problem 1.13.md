### Формулировка
<div class="lang-pair"><label class="lang-btn"><input class="lang-sw" type="checkbox"><span class="is-ru">ru</span><span class="is-en">en</span></label><div class="lang-ru"><p>Система с двумя CPU, на каждом по два потока (hyperthreading). Три программы P0, P1, P2 со временами 5, 10 и 20 msec.</p><p>За сколько закончится выполнение? Все программы 100% CPU-bound, не блокируются и не меняют CPU после назначения.</p></div><div class="lang-en"><p>Consider a system that has two CPUs, each CPU having two threads (hyperthreading). Suppose three programs P0, P1, and P2 are started with run times of 5, 10 and 20 msec, respectively.</p><p>How long will it take to complete the execution of these programs? Assume that all three programs are 100% CPU bound, do not block during execution, and do not change CPUs once assigned.</p></div></div>

### Ответ
<div class="lang-pair"><label class="lang-btn"><input class="lang-sw" type="checkbox"><span class="is-ru">ru</span><span class="is-en">en</span></label><div class="lang-ru"><p>4 logical processor ≠ 4 полноценных ядра. HT — второй поток на <i>том же</i> физическом CPU (кэш/ALU общие). Физических пакетов по-прежнему <b>два</b>.</p><p>«Не меняют CPU» значит: после посадки программа не уезжает на другой пакет. Итог = насколько перегрузили самый занятый <i>физический</i> CPU.</p><p>Диапазон туториала: <b>20</b> msec (P2 одна на пакете, P0+P1 ≤ 20), <b>25</b> (5+20), <b>30</b> (10+20), до <b>35</b> если всех троих запихнули на один пакет (5+10+20). HT не true parallelism.</p><p>Таблица: <a class="internal-link" data-href="Hyperthreading scheduling" href="Hyperthreading scheduling">Hyperthreading scheduling</a>.</p></div><div class="lang-en"><p>4 logical processors ≠ 4 full cores. HT is a second thread on the <i>same</i> physical CPU (shared cache/ALU). There are still only <b>two</b> packages.</p><p>“Do not change CPUs” means a program stays on the package it was assigned. Finish time = how loaded the busiest <i>physical</i> CPU is.</p><p>Tutorial range: <b>20</b> msec (P2 alone on a package, P0+P1 ≤ 20), <b>25</b> (5+20), <b>30</b> (10+20), up to <b>35</b> if all three share one package (5+10+20). HT is not true parallelism.</p><p>Table: <a class="internal-link" data-href="Hyperthreading scheduling" href="Hyperthreading scheduling">Hyperthreading scheduling</a>.</p></div></div>
