### Ответ

<div class="lang-pair">
<input class="lang-sw" type="checkbox" id="p13-a"><label for="p13-a"></label>
<div class="lang-ru">

Multiprogramming — несколько программ на одной машине одновременно. Time-sharing — несколько пользователей делят ресурсы одновременно. Все TS-системы суть MP, не все MP — TS.

</div>
<div class="lang-en">

Multiprogramming is running several programs on one computer at the same time. Time-sharing is sharing computing resources among several users at the same time. Every time-sharing system is a multiprogramming system; not every multiprogramming system is time-sharing.

</div>
</div>
