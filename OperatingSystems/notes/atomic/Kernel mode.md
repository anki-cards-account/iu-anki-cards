**Мини-словарь:**
- kernel mode — режим процессора с полным доступом к железу (также supervisor mode).
- privileged instruction — инструкция, которую в user mode выполнять нельзя.

Milestone: [[OS Lection 1 - введение]], [[OS Tutorial 1 - введение]]
Problem: [[Problem 1.10]]

### Концепт

Представь два ключа от одной машины: у ОС — полный комплект (руль, зажигание, капот), у браузера — только «ехать по дороге». Kernel mode — полный комплект. Если бы почта тоже крутила I/O как ей вздумается, система развалилась бы.

### Под капотом

Большинство компьютеров имеют **два режима**: [[Kernel mode]] и [[User mode]].

ОС работает в kernel mode (supervisor mode) и:

- имеет **полный доступ ко всему hardware**;
- может выполнить **любую** инструкцию и обратиться к **любому** адресу памяти.

Это режим самых доверенных функций ОС. **Crash в kernel mode катастрофичен** — останавливает весь PC.

Именно поэтому драйверы и ядро должны жить здесь. Пользовательская программа получает услуги ОС только через [[System call]] (TRAP). Два режима изолируют код: см. [[User mode]].

Связано: [[Device driver]] (должен быть в ОС, чтобы бежать в kernel mode).
