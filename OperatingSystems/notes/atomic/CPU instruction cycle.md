**Мини-словарь:**
- instruction cycle — повторяющийся цикл работы CPU: взять команду → выполнить → записать результат.
- opcode — код операции в инструкции.

Milestone: [[OS Lection 1 - введение]]

### Концепт

Процессор не «думает», он крутит один и тот же конвейер шагов над следующей инструкцией. Если застрял на fetch из памяти — это дорого; отсюда кэш, pipeline, потоки.

### Под капотом

Базовый цикл **каждого** CPU:

1. **Fetch Instruction** — прочитать следующую ожидаемую инструкцию в буфер.
2. **Decode Instruction** — определить opcode и спецификаторы операндов.
3. **Calculate Operands** — эффективный адрес каждого source operand.
4. **Fetch Operands** — взять операнды из памяти (из регистров **не** надо).
5. **Execute Instruction** — выполнить операцию и получить результат.
6. **Write Operand** — сохранить результат в память.

Дальше ускорения: [[Instruction pipeline]] (стадии параллельно), [[CPU registers]] (не ходить в память за временными значениями), [[Cache]].
