**Мини-словарь:**
- cache line — кусок main memory, обычно 64 bytes; единица хранения в кэше.
- cache hit — нужная line уже в кэше, по шине в RAM **не** идём.
- eviction — кого выкинуть из кэша, когда нужен слот.

Milestone: [[OS Lection 1 - введение]]

### Концепт

Кэш — «стол рядом с CPU»: самые горячие 64-байтные строки лежат близко. Попал — ~2 такта. Не попал — поездка в main memory по шине.

### Под капотом

- Main memory режется на **cache lines**, typically **64 bytes**. Самые used lines держат в high-speed cache **внутри CPU**.
- При чтении слова hardware проверяет, есть ли line в кэше. **Hit** → запрос в main memory по шине **не** отправляется. Обычно **около 2 clock cycles**.
- Бывает **два или три уровня** кэша: каждый следующий **медленнее и больше**.

**Caching system issues** (что система должна решить):

1. когда класть новый item в кэш;
2. в какую cache line его класть;
3. какой item **удалить**, когда нужен слот;
4. куда положить newly evicted item в большей памяти.

Место в иерархии — [[Memory hierarchy]]. Неудовлетворённые из кэша запросы идут в RAM ([[Memory types]]). У многоядерников L1/L2 раскладки — [[Multicore]].
