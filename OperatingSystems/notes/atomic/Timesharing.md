**Мини-словарь:**
- multiprogramming — в памяти (на машине) **одновременно живут несколько программ**. Пока одна ждёт диск, CPU не простаивает — крутит другую. Пользователей за терминалами может не быть: пачка jobs в очереди тоже MP.
- time-sharing (timesharing) — вычислительные ресурсы делят **несколько пользователей одновременно**, обычно интерактивно (каждый думает, что машина «его»).
- не путать с [[Multiplexing]]: там оси time vs space у **одного ресурса** (CPU по очереди vs диск нарезанный). Time-sharing — частный случай разделения CPU во времени между **людьми**.

Milestone: [[OS Tutorial 1 - введение]]
Problem: [[OS Problem 1.3]]

### Концепт

Ось не «быстро / медленно». Ось **что делим**:

- MP: несколько **программ** в одной машине (чтобы CPU не спал на I/O).
- TS: несколько **пользователей** в одно время (чтобы люди не ждали ночную смену).

Следствие, которое любят на экзамене: **всякая TS-система — MP**, потому что несколько пользователей ⇒ несколько программ в системе. **Не всякая MP — TS**: сервер может крутить пачку jobs без интерактива и без «нескольких людей за раз».

### Под капотом

Ответ туториала (problem 1.3):

- **Multiprogramming** = allocation of multiple programs on one computer **simultaneously**.
- **Time-sharing** = sharing of computing resources among **several users at the same time**.
- **Все** timesharing-системы суть multiprogramming-системы, **но не все** multiprogramming-системы — timesharing.

Контрпример MP без TS: пакетная система 2-го поколения — в памяти несколько jobs, пользователей «сейчас за экраном» нет ([[History of OS]]). Time-sharing появляется в 3rd generation; как сервис — типичный mainframe ([[OS Zoo]]).
