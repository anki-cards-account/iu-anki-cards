**Мини-словарь:**
- operating system (OS) — слой ПО между железом и пользовательскими программами.
- abstraction — упрощённая модель ресурса (например, «блоки диска» вместо контроллера).

Milestone: [[OS Lection 1 - введение]], [[OS Tutorial 1 - введение]]
Problem: [[Problem 1.1]]

### Концепт

ОС — не «ещё одна программа», а **слой**, который решает две задачи сразу: дать программам понятную машину и не дать им подраться за железо. На экзамене определение почти всегда двусоставное.

### Под капотом

OS — слой software, который:

1. даёт user programs **лучшую, проще и чище** модель компьютера;
2. **управляет всеми ресурсами**.

Формулировка с туториала (экзамен, две main functions): **resource management** и **fine abstractions from the bare metal**.

Это две стороны одной медали: сверху — [[Extended Machine]], снизу — [[Resource Manager]]. Без первого программист видит хаотичные интерфейсы железа; без второго несколько программ одновременно ломают процессор, память и I/O.

Связано: [[Kernel mode]] (где живёт ОС), [[User mode]] (где живут остальные программы).
