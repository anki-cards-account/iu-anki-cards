**Мини-словарь:**
- extended machine — ОС как «улучшенный процессор»: скрывает железо за абстракциями.
- disk driver — пример абстракции: вместо адского интерфейса диска — read/write блоков.

Milestone: [[OS Lection 1 - введение]], [[OS Tutorial 1 - введение]]
Problem: [[Problem 1.1]]

### Концепт

Взгляд **сверху вниз**. Железо неудобное и разное. ОС говорит программисту: «вот диск из блоков, читай/пиши» — и сама дерётся с контроллером. Это и есть «расширенная машина»: instruction set + понятные объекты вместо сырого hardware.

### Под капотом

**Проблема:** hardware очень сложный и даёт software developers трудные и **несогласованные** интерфейсы.

**Решение:** абстракции. Пример — disk driver: работает с железом и даёт интерфейс **читать и писать disk blocks**.

Это одна из двух ролей [[Operating System]] (вторая — [[Resource Manager]], взгляд снизу вверх). Драйвер при этом должен быть в ядре, см. [[Device driver]].
