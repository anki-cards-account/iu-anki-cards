**Мини-словарь:**
- system call — запрос услуги у ОС из user-программы.
- TRAP — механизм процессора: прерывание/ловушка, вход в ядро.

Milestone: [[OS Lection 1 - введение]], [[OS Tutorial 1 - введение]]
Problem: [[Problem 1.10]]

### Концепт

System call — «официальная дверь» в ядро. Не прыжок по адресу ядра как попало, а контролируемый TRAP: процессор сам переключает режим и отдаёт управление ОС.

### Под капотом

Из [[User mode]] программа **не имеет** права выполнять I/O и управляющие инструкции. Единственный путь к сервису ОС:

1. программа делает **system call (TRAP)**;
2. hardware делает trap **в ядро**;
3. CPU оказывается в [[Kernel mode]];
4. вызывается ОС, выполняет запрос, возвращает управление.

На экзамене: system call = способ получить услугу ОС, не нарушая границу режимов. Связано с тем, зачем нужны два режима ([[Kernel mode]], [[User mode]]).
